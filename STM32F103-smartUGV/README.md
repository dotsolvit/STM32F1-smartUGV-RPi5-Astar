# STM32F103-smartUGV — Firmware (C / STM32CubeIDE)

Прошивка контролера реального часу на базі мікроконтролера **STM32F103C8T6** (ARM Cortex-M3, тактування `HCLK = 72 MHz`). Забезпечує опитування сенсорів, Sensor Fusion, диференціальну одометрію, керування приводами шасі, сканування перешкод та бінарний обмін даними з ESP32-CAM.

---

## Архітектура ПЗ та структура файлів

Прошивка побудована без використання RTOS за принципом **подієво-орієнтованого суперциклу (Superloop + Non-blocking State Machines)** із жорстким розділенням відповідальності між модулями:

* **`Core/Src/main.c` & `Core/Inc/main.h`** — ініціалізація периферії, диспетчер головного циклу (`while(1)`), асинхронний таймер відправки телеметрії (50 мс), обробка стану калібрування, структури бінарних пакетів та прямий запис у регістр `USART2->DR`.
* **`Core/Src/stm32f1xx_it.c`** — обробники апаратних переривань. Містить скінченний автомат (State Machine) прийому вхідних пакетів по `USART2_IRQHandler` (`0xAA 0xB1` — команди керування, `0xAA 0xB2` — потік координат маршруту A\*) з перевіркою `CRC8`.
* **`Core/Src/telemetry_module.c` & `Core/Inc/telemetry_module.h`** — модуль оцінки стану (State Estimation):
  * Диференціальна одометрія по енкодерах лівого та правого бортів (з урахуванням напрямку обертання).
  * Злиття даних гіроскопа `MPU6050` (50 Гц) та магнітометра `HP5883` (10 Гц) через комплементарний фільтр із коректною обробкою переходу через `0°/360°` та фіксацією курсу в стані спокою (ZUPT).
  * Кругове калібрування магнітометра (Hard-Iron offset) із записом/зчитуванням коефіцієнтів у внутрішню **Flash-пам'ять** STM32.
  * Опитування АЦП (напруга LiPo 2S із програмним ФНЧ та аналоговий сигнал Sharp IR).
* **`Core/Src/pilot_module.c` & `Core/Inc/pilot_module.h`** — модуль керування рухом (Motion Control & Navigation):
  * Неблокуючий кінцевий автомат навігації (`NAV_IDLE`, `NAV_TURNING`, `NAV_DRIVING`, `NAV_COASTING`, `NAV_WIDE_SCANNING`).
  * Профілювання швидкості двигунів: стрибок через мертву зону ШІМ (`MOTOR_MIN_PWM = 68`), плавний розгін/гальмування, зона уповільнення перед точкою (`15 см`), П-регулятор утримання курсу (`kp = 1.8`) та фіксація повної зупинки по інерції (60 мс без імпульсів енкодерів).
  * Керування сервоприводом сканера (MG90S) та кусково-лінійна інтерполяція відстані далекоміра Sharp GP2Y0A02YK0F (200–1500 мм) у режимах вузького (`±11°`) та панорамного (`-90°...+90°`) огляду.
* **`Core/Src/adc.c`** — низькорівнева обгортка `ADC_ReadChannel()` для незалежного послідовного опитування регулярних каналів АЦП.
* **Драйвери сенсорів (`mpu6050.*`, `hp5883.*`)** — власні бібліотеки роботи з IMU та магнітометром по шині I2C.

## Конфігурація периферії (STM32CubeMX)

| Периферія | Піни | Параметри налаштування | Призначення |
| :--- | :--- | :--- | :--- |
| **SYS / RCC** | `PA13`, `PA14` | HSE 8 MHz → PLL `72 MHz`, SWD Debug | Системне тактування та відлагодження |
| **TIM1** | `PA8` (CH1) | `PSC = 71`, `ARR = 19999` (50 Гц, 1 мкс/тік) | ШІМ керування сервоприводом MG90S (`460..2400 мкс`) |
| **TIM2** | Внутрішній | `PSC = 71`, `ARR = 0xFFFFFFFF` (1 МГц) | Мікросекундний хронометр для обчислення `dt` гіроскопа |
| **TIM3** | `PB4` (CH1), `PB5` (CH2) | Partial Remap, Input Capture (Rising Edge, Filter 4), NVIC IRQ | Апаратне захоплення імпульсів лівого та правого енкодерів |
| **TIM4** | `PB6`–`PB9` (CH1–CH4) | `PSC = 71`, `ARR = 99` (10 кГц), Preload Enabled | 4-канальний ШІМ керування драйвером двигунів DRV8833 |
| **ADC1** | `PA0` (IN0), `PA1` (IN1) | 12-bit, Scan Disabled, Continuous Disabled, `71.5 Cycles` | `PA0`: вольтметр АКБ (дільник `3.119`); `PA1`: Sharp IR |
| **I2C2** | `PB10` (SCL), `PB11` (SDA) | Standard/Fast Mode, NVIC Event/Error IRQ | Шина сенсорів: MPU6050 (`0x68`) та компас HP5883 (`0x2C`) |
| **USART2** | `PA2` (TX), `PA3` (RX) | `115200 бод`, 8-N-1, NVIC Global Interrupt | Асинхронний бінарний міст із ESP32-CAM |

## Специфікація бінарного протоколу UART

Для мінімізації затримок та захисту від втрати синхронізації використовується бінарний протокол із двобайтними заголовками, вирівнюванням структур `#pragma pack(push, 1)` та контрольною сумою **CRC8 (Dallas/Maxim, поліном `0x8C`)**.

### Вхідні пакети (ESP32-CAM → STM32, маркер `0xAA`)
* **`0xAA 0xB1` (Control Packet, 4 байти):** команда зміни стану (`1` — Start, `2` — Stop, `3` — Calibrate).
* **`0xAA 0xB2` (Path Point Packet, 12 байт):** потокова передача координат маршруту A\* (`float x`, `float y`, `uint8_t is_last`).

### Вихідні пакети (STM32 → ESP32-CAM, маркер `0xDE`)
Для уникнення жорстко заданих зміщень поле `crc8` розташоване третім байтом — контрольна сума автоматично обчислюється для всього корисного навантаження через `sizeof(Packet) - 3`:
* **`0xDE 0x01` (Telemetry Packet, 17 байт):** передається кожні 50 мс (`x`, `y`, `theta_deg`, `battery_pct`, `status_code`).
* **`0xDE 0x02` (Scan Point Packet, 8 байт):** передається покроково під час панорамного сканування (`angle`, `distance_mm`, `is_end_of_scan`).

## Збірка та прошивка

1. Відкрийте проєкт у **STM32CubeIDE** (`File -> Open Projects from File System...`).
2. Зберіть проєкт (`Project -> Build All`, компілятор `arm-none-eabi-gcc`).
3. Прошийте мікроконтролер через програматор **ST-Link V2** (SWD).

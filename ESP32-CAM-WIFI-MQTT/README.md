# ESP32-CAM Wi-Fi MQTT Шлюз (Bridge)

Цей модуль є частиною системи керування **Smart UGV**. Він виконує роль високошвидкісного бездротового шлюзу-перекладача, який зв'язує стаціонарний навігаційний сервер **Raspberry Pi 5** (через протокол MQTT/JSON) та бортовий мікроконтролер **STM32F103C8T6** (через апаратний асинхронний UART/Бінарні пакети з CRC8).

---

## 🛠️ Середовище розробки та Налаштування плати

Програма написана в **Arduino IDE**. Для успішної прошивки модуля ESP32-CAM використовуйте такі налаштування:

1. **Менеджер плат (Boards Manager):** Встановіть пакет плат `esp32`.
2. **Обрана плата:** `AI Thinker ESP32-CAM`.
3. **Частота ядра (Flash Frequency):** `80MHz`.
4. **Схема розділів (Partition Scheme):** `Huge APP (3MB No OTA/1MB SPIFFS)` — *критично для стабільної роботи Wi-Fi та мережевого стеку*.
5. **Швидкість завантаження (Upload Speed):** `115200`.

> ⚠️ **Режим прошивки (Boot Mode):** Для заливки скетчу необхідно замкнути контакт **GPIO0 на GND** перед подачею живлення. Після завершення прошивки розімкніть цей контакт, щоб модуль завантажився в робочому режимі. На час прошивки виймайте джампери зв'язку з STM32 (`PA2/PA3`), щоб уникнути конфлікту ліній UART.

## 🏗️ Архітектура програми

Програма побудована за **повністю асинхронним принципом** (без використання блокуючих функцій `delay()`), що дозволяє одночасно обробляти мережеві події та тримати високий темп передачі даних по UART.

1. **Ініціалізація та індикація:** Під час підключення до Wi-Fi вбудований спалах (Flash LED) плавно поблискує. Після успішного з'єднання з мережею та MQTT-брокером світлодіод переходить у режим постійного слабкого свічення, сигналізуючи про готовність системи.
2. **Downlink (MQTT -> UART):** Обробник `mqttCallback` приймає JSON-повідомлення від Raspberry Pi 5, миттєво конвертує їх у компактні бінарні структури, рахує апаратну контрольну суму `CRC8` (Dallas/Maxim) і відправляє в STM32.
3. **Uplink (UART -> MQTT):** Функція `handleUartRx()` у реальному часі вичитує потік байт із шини UART, фільтрує шум за допомогою унікальних стартових маркерів (хедерів), перевіряє цілісність по `CRC8` і публікує телеметрію або масиви сканування перешкод у топіки брокера у форматі JSON.

## 📡 Протокол обміну

### 1. Взаємодія з MQTT-брокером (Raspberry Pi 5)

* **`robot/control` (Вхідний JSON):** Команди загального керування UGV.
  * *Формат:* `{"command": "start"}` (доступні значення: `"start"`, `"stop"`, `"calibrate"`).
* **`robot/path` (Вхідний JSON):** Масив точок зламу траєкторії від алгоритму A*.
  * *Формат:* `{"points": [{"x": 4.05, "y": 4.05}, {"x": 5.80, "y": 5.20}]}`.
* **`robot/telemetry` (Вихідний JSON):** Поточний стан робота (частота до 20 Гц під час руху).
  * *Формат:* `{"x": 4.35, "y": 2.10, "theta_deg": 125.5, "battery_pct": 87, "status": "moving"}`.
* **`robot/obstacle_scan` (Вихідний JSON):** Результат панорамного огляду датчиком Sharp IR (відсилання строго одним пакетом після завершення сканування).
  * *Формат:* `{"angles": [-90, 0, 90], "distances": [1500, 320, 1500]}`.

### 2. Взаємодія з STM32F103 (UART 115200 бод)

Усі пакети вирівняні по одному байту за допомогою `#pragma pack(push, 1)`.

* **Пакет команд керування (`0xAA 0xB1`):**
  `[0xAA][0xB1] [uint8_t action] [uint8_t crc8]` *(Розмір: 4 байти)*.
* **Пакет точки шляху (`0xAA 0xB2`):** Потокова передача координат по одній точці.
  `[0xAA][0xB2] [float x] [float y] [uint8_t is_last] [uint8_t crc8]` *(Розмір: 12 байт)*.
* **Пакет телеметрії від STM32 (`0xDE 0x01`):**
  `[0xDE][0x01] [float x] [float y] [float theta_deg] [uint8_t battery_pct] [uint8_t status_code] [uint8_t crc8]` *(Розмір: 17 байт)*.
* **Пакет сканування від STM32 (`0xDE 0x02`):**
  `[0xDE][0x02] [int16_t angle] [uint16_t distance_mm] [uint8_t is_end_of_scan] [uint8_t crc8]` *(Розмір: 8 байт)*.

## 🔒 Налаштування безпеки мережі
Для захисту приватних даних авторизації у репозиторії опубліковано файл `myssid.h.example`. Перейменуйте його на `myssid.h` та вкажіть параметри своєї Wi-Fi локальної точки доступу:
```cpp
#define MY_WIFI_SSID "Назва_Вашої_Мережі"
#define MY_WIFI_PASS "Ваш_Пароль"
```
Файл `myssid.h` автоматично внесено до `.gitignore` і він ніколи не потрапить у публічний доступ.
